# DraftDiff

A real-time League of Legends draft analysis and recommendation tool.

---

## 📌 Core Architecture

The project is a **decoupled system** composed of three main parts: a desktop application, a data storage bucket, and an automated data pipeline.

1. **Frontend (Electron Application)**  
   A self-contained program that runs on the user's machine. It connects to the live League of Legends client (LCU) and fetches statistical data directly from a public Cloudflare R2 bucket. All data processing and algorithm calculations happen client-side.

2. **Data Storage (Cloudflare R2)**  
   A publicly accessible S3-compatible object storage bucket that hosts static JSON datasets generated by the data pipeline.  
   **Public URL:** [Cloudflare R2 Bucket](https://pub-1efd88d862814361909e5510d7af1c1a.r2.dev)

3. **Data Pipeline (GitHub Actions)**  
   An automated, scheduled process that scrapes the latest data from **LoLalytics**, processes it into the required format, and uploads it to the Cloudflare R2 bucket for the desktop client to consume.

---

## 🛠️ Technology Stack

- **Frontend:** Electron, HTML, CSS, JavaScript (no framework)  
- **Data Pipeline:** Python, GitHub Actions (automation)  
- **Data Storage:** Cloudflare R2 (S3-compatible object storage)

## 🔍 Component Breakdown

### 1. Frontend (Electron App)

- **Location:** `/desktop-app/`  
- **Description:** A desktop application built with web technologies. It is the only component the end-user interacts with directly. It fetches data directly from Cloudflare R2.  
- **Key Files:**  
  - `index.html`: Main UI and all client-side application logic (data fetching + algorithm execution)  
  - `main.js`: Electron main process (window creation, LCU connection, secure file system access)  
  - `preload.js`: Securely exposes backend functions from `main.js` to the frontend  
  - `package.json`: Defines dependencies and build scripts  

#### ▶️ To Run Locally
```bash
cd desktop-app
npm install
npm start
```

#### 📦 To Build Installer
```bash
cd desktop-app
npm run dist
# Installer will be in /desktop-app/dist/
```

---

### 2. Data Pipeline (GitHub Actions)

- **Location:** `/scripts/` and `/.github/workflows/`  
- **Description:** Automatically scrapes data from **LoLalytics** and uploads it to the Cloudflare R2 bucket. Runs on a schedule with no manual intervention.  
- **Key Files:**  
  - `scripts/scrape_lolalytics.py`: Python script that scrapes and uploads data  
  - `.github/workflows/update_data.yml`: GitHub Actions config (cron schedule: `0 6,18 * * *`)  

#### 🔄 Manual Trigger  
You can run the data update job manually via the **"Actions"** tab in GitHub.

## 🔑 Key Credentials & Environment Variables

⚠️ **DO NOT COMMIT SECRET KEYS TO THE REPOSITORY.**

For the Data Pipeline (GitHub Actions), the following secrets must be configured in:  
`GitHub Repo -> Settings -> Secrets and variables -> Actions`

- `CLOUDFLARE_ACCOUNT_ID`  
- `AWS_ACCESS_KEY_ID`  
- `AWS_SECRET_ACCESS_KEY`

## 🚀 Development Workflow

### Updating the UI / Frontend Logic
1. Modify files in `/desktop-app/`  
2. Test locally using:
   ```bash
   npm start
   ```
3. When complete, build a new installer:
   ```bash
   npm run dist
   ```
4. Distribute the new `.exe`

### Updating the Data Scraper
1. Modify `scripts/scrape_lolalytics.py`  
2. Commit and push to `main`  
3. The next scheduled GitHub Action will use the updated script
