# DraftDiff v4.6.0

This update makes draft recommendations easier to understand and share.

- **A clearer quick start:** How To Use explains the main workflow, with the
  detailed math behind an expandable section. The desktop guide explains how
  live tracking estimates roles and when manual moves and role locks can help.
- **Help where you need it:** Tooltips explain the filters and Hovers. One help
  button beside the recommendation columns explains Total, Lane, Ally, Enemy,
  Base WR and Role Freq without changing your sort order.
- **High Delta 2 reference:** Compare your suggestions with Sylas MID versus
  Malphite MID in the selected dataset. Both directional values are shown, with
  low-sample warnings where relevant. The reference starts collapsed and remembers
  whether you expand or collapse it.
- **COPY TOP 10:** Copy up to ten available recommendations in the displayed
  order, respecting your filters and sorting, ready to paste into champion-select
  chat. The text includes the role and says it is based on the current draft.
- **Desktop update notices:** The version sits beside the DraftDiff title. Click
  it to check for updates; an Update available button appears when there is a newer
  release and opens the download page. Installation remains manual.

The guidance, reference and sharing improvements are available in both versions.
Live champion-select tracking remains a desktop feature; the web app supports
manual drafting and links to the desktop download.

## Installing on Windows

Download the Windows installer attached to this release, close DraftDiff, and run
the installer. Existing users need to install this version manually to receive
the new update notices.

The installer is unsigned. Windows may warn about or block it, including on PCs
with Smart App Control enabled.
